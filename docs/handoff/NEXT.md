## 本轮落点

FAT32 两处原始写入已改成内核私有兼容写入器；按设备串行、永久持有写 DMA 页，
分段写出、核对封存快照与真实几何，非忙 I/O 错误阻止该设备后续服务读写并隔离页。
返回完成前缀但不承诺失败段未写；无自动重试/回滚/热恢复。模块 ABI 仍 1.5、块协议 v2，
WRITE RPC 仍 EROFS，不增加模块写盘权限。内核私有写入口不是已完成的写消息服务。

FAT32 同卷修改互斥且忙立即失败；写数据/目录更新错误不再被忽略，全部成功后才发布
内存元数据/offset。新簇先清零再链接；成功更新两份 FAT，部分失败停写而不盲目回滚；
删除目录项失败不清链。拒绝稀疏写，失败可能留下部分数据/孤立簇，需要离线修复。

实现、验证实测及边界见 [兼容写入对接](../integration/20261019-fat32-write-guard.md)。
