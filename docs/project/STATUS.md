## 现在能做什么

UEFI 引导进入 Core 0 与隔离用户态，提供能力 IPC、抢占、进程/内存和浮点上下文隔离。用户态管理器可装卸模块、固定依赖代次并监督 echo/native；提供 RAM 文件/目录、受控只读目录委派和 virtio 磁盘访问。签名应用支持 argv、显式环境与受限位置无关装载；持久化原型提供笔记、一个应用的 A/B 更新、健康确认/失败回退、软件版本下限和密钥撤销。

## 验证边界与下一步

当前事务卷仍是最多五个文件、每个上限 16 KiB 的原型，面向笔记和一个应用双槽；文件 SDK 不等于通用文件系统。native 没有动态库、TLS 或完整导入支持；PI 基址选择不是安全随机化。设备隔离仅覆盖已测试 Q35/单设备范围，QEMU 结果不替代真实硬件/IRQ/断电验收。
