## 缺陷与有界改动

原读取器仅分配连续的 392 字节头部数组，丢失变长值；安装器误以为值紧跟返回的头，
会从另一个头或数组之外读取。原读取器还允许截断值、过量计数、未终止字符串，
安装器未释放返回数组，也未传播写入失败。

新增 `sfk_get_reg_views`：先验证头/权限前缀和全部注册表记录，再分配视图数组。
每视图复制记录头，值指针借用稳定的输入快照；数组由调用者 kfree 一次，值不单独释放。
明确每包最多 64 条、每值最多 REG_MAX_VALUE_DATA=4096，拒绝畸形声明，不改变 v1 线布局。
原 `sfk_get_reg_entries` 签名保留，作为严格校验后的头部数组兼容接口，明确不携带值。

安装器在 grants、DRYRUN 和安装副作用之前取得完整视图；实际写入使用原输入中的有界值。
成功、DRYRUN、OOM、注册/打开键/写值失败路径均回收数组及输入快照，已打开的键会关闭。
后端错误明确返回失败；此前已发生的目录/注册表写入不回滚，不等于安装事务。
这是内核内部 C 接口，不是跨服务指针协议；模块 ABI 1.5、SFK 头与记录线布局不变。
