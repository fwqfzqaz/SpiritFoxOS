# 重构记录

## 2026-10-18：tmpfs 兼容路径迁移

对应参考文档 D1/D2 与“/tmp、/run -> fs.tmpfs”的下一步实现，不把整套设备/进程迁移
计为完成。三处启动挂载 /modules、/tmp、/run 使用同一模块后端的独立根，保留原根
memfs、FAT32、devfs、procfs 与驱动调用路径。

- ABI 升为 1.1，目录句柄、树形路径、mkdir/readdir、符号链接存储、retain/release；
  旧 ABI 包需一起重新编译。64 节点共享配额、63 字节名称、单文件 64 KiB。
- 普通 Linux 文件调用实际进入模块；unlink 后已打开的文件继续可用，重建同名文件
  不改变旧描述。dup/fork 共享描述，最后 close、进程退出和 exec 的关闭走统一回收。
- 目录项在发布后端节点前分配；命名空间修改/open/最后关闭串行，挂载根不能 rmdir，
  卸载拒绝时保持挂载记录。修复超长组件被拆分或截断别名、挂载目录的 .. 解析。
- 修正 VFS O_TRUNC/O_APPEND/O_DIRECTORY 与 Linux 数值不一致，按权限处理普通文件
  读写/截断，追加时重新取文件尾；关闭使用预留 RPC 缓冲区，不因临时 OOM 遗失引用。
- 新增模块层独立根/目录/旧句柄、满配额和首次写入 OOM 恢复测试；用户态检查嵌套目录、
  getdents64、删除后 dup/fork 引用、同名重建、独立根、截断/追加、80 次回收及名称边界。
  原模块加载、16 子进程和 Wayland 启动检查继续执行。

仍未实现动态多后端挂载、rename、完整 POSIX 权限与硬件故障隔离。目录缓存与符号链接
解析仍由旧 VFS 提供，不能把 tmpfs 迁移表述为整个 VFS/Linux ABI 已搬出内核。
实际最终提交及 CI 验证结果由仓库外任务进度记录保存，不在此提前宣称通过。

## 2026-10-18：环境基线与模块化第一阶段

采用经用户确认的分阶段迁移，不同时替换整个内核。现有源文件保持原路径，
新增 `kernel/core` 与独立 `modules`，未删除旧功能。

### 可重复构建

- 固定 musl 1.2.5、libffi 3.4.6、Wayland 1.23.1 的源码与校验值。
- 兼容 Ubuntu/Arch 的编译器命名、OVMF 布局、GNU C 标准变化，保持 CROSS 覆盖。
- 使用外部 sysroot 和匹配版本的宿主 scanner，避免宿主库/生成头污染仓库。
- LF、可执行权限、源码检查、提交快照推送钩子和双发行版 CI。

### 已修复的启动与运行阻塞

- EFI 新 section 表超出原 SizeOfHeaders，覆盖入口代码；扩展对齐的头部并修正
  原始数据与符号表偏移。添加无空闲头部的 PE 回归测试。
- exec 的 argv/env 临时数组超过 8 KiB 内核栈；改用堆，提前保存参数并在失败时释放。
  新进程从原始内核页表深拷贝页表页，避免覆盖旧程序/父进程的用户映射。
- Wayland 客户端提交后销毁 buffer，合成器继续读取已解除映射的像素；commit 时
  取得服务器快照，修复 pending buffer 生命周期，检查共享池/缓冲区几何边界。
- 修正网络长度指针、registry 列表行宽等编译暴露的问题。
- ftruncate 分派给文件系统操作，确保实际文件数据与 inode 大小一致。
- 定时器重入调度器导致进程切换错乱；切换期间关闭中断，返回各自栈后恢复。
  修正 wait 的丢失唤醒窗口、匹配目标 pid，并仅在确实等待 vfork 时于 exec 唤醒父进程。
  exec 创建新页表期间被抢占，调度器恢复其内核执行时使用内核页表，避免向 CR3 写入零占位值。

### 已实现的模块机制

- 96 字节元数据、64 字节消息头和版本化核心 API 表。
- 有界端点队列、同步内核内 RPC、代数句柄、生命周期/依赖检查。
- ET_REL section、符号和重定位检查，启动包构建和拓扑加载。
- 实际加载 `demo.hello`、`fs.tmpfs`、`fs.vfs`；通过消息完成文件操作。
- `/modules` VFS 兼容桥，普通 shell/用户程序能访问模块后端文件。

### 验证范围

环境验收使用 Ubuntu GCC 13.3/NASM 2.16 与 Arch GCC 16.2/NASM 3.02。
两套产物分别在 Windows QEMU TCG 中通过 UEFI 启动；Arch 是独立根文件系统的
用户空间构建，不是原生启动 Arch 内核的编译机。

宿主 UBSan 测试覆盖坏 ELF/包、截断输入、依赖缺失/循环、失败回滚、OOM、队列与
文件操作。QEMU 检查模块加载、IPC/文件自测、用户态创建/截断/读写/删除和 Wayland
窗口及至少 10 帧，另运行 16 个子进程的 fork/exit/wait 压力测试，继续观察 3 秒并拒绝任何已知异常标记。
推送钩子重新验证最终提交快照；远端 Actions 的实际结果以 GitHub 运行记录为准。

### 后续阶段

本版仍是宏内核兼容路径加受信任插件；尚未迁移 PCI/AHCI/tty/进程/Linux ABI 为
独立模块，尚无 Ring 3 驱动隔离、超时/阻塞 IPC、完整能力模型和驱动监督重启。
保留现有分配器/调度器，不宣称实现了新的 buddy/SMP 调度。BIOS、ext4、网络和
真机未在本次验收覆盖。详见 ARCHITECTURE.md 和 SFMOD-ABI.md。
